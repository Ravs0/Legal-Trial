# LexForge — Full Application Audit (2026-08-21)

Scope: every file, every feature, line-by-line. Method: full source read, mechanical scans (dead code, type health, a11y, deps), contract/stress tests, bundle analysis. Severity: 🔴 fix now · 🟡 should fix · 🟢 nice-to-have · ⚪ note. "Harmony rule" applies throughout: nothing here recommends breaking the Paper Dossier system, the signed-state architecture, or the honest-capability labels.

## 1. Executive summary

LexForge is ~43k lines across a React 19/Vite frontend, five Vercel serverless functions (Node + one Python), and a Python logic-duel engine. The audit covered every module: full line-reads of the Dreadler engine, API layer, scoring services, and the five largest screens; structured reads of the remainder; mechanical scans (dead code, type health, a11y, dependency advisories, bundle composition); and the existing 51-test contract/TS suite as the stress baseline.

**Verdict: the architecture is sound and several modules are genuinely excellent** — `storageService` (versioned envelopes, shape guards, quota recovery), `PracticeArena`'s turn engine (stream watchdogs, rollback, resume), the Dreadler contract-test culture, and a privacy posture (analytics local-only, query *lengths* tracked never contents) most commercial apps don't bother with. No security holes in the app's own code; the signed-state design holds.

**The real debt is threefold:**
1. **~250 invisible-surface remnants** from the Paper Dossier migration (`white/N` classes that render white-on-paper) — the single largest defect class, including broken primary CTAs in the Draft Sandbox and invisible data-viz bars on Home. Mechanical fix, ~half a day.
2. **5 npm advisories (3 high)** — all fixed by `npm audit fix`; the react-router RSC CSRF one does not apply to this app's HashRouter usage but should be patched regardless.
3. **Copy-law and consistency drift**: StrategyRoom and DraftingStudio interiors still carry pre-redesign verbose copy, bracket cosplay, a legacy dark SVG palette, and bypass the app's own storage service with unguarded raw `localStorage`.

Everything else is polish. Detailed findings, file:line, and a phased roadmap follow.

## 3. Findings by module

### 3.1 Cross-cutting: Paper Dossier migration gaps (post-codemod)

- 🔴 **~250 `bg-white/N` / `border-white/N` / `ring-white/N` remnants** on light screens (StrategyRoom 28, CourtSources 23, DraftingStudio 19, AIPersonas 19, Performance 14, Landing 14, OversightSpirit 14, ScoreCard 10, CommandPalette 10, ChatMessage 10, PracticeArena 9, lexide×3, BenchCounsel 6). The codemod mapped only bracketed forms (`bg-white/[0.04]`); slash forms (`bg-white/5`, `/10`, `/15`, `/25`) render white-on-paper = invisible borders/badges/hovers. Fix: mechanical map `white/N` → `ink/N` equivalents on all non-arena files; ~30 min.
- 🟡 **6 bare `hover:bg-white` + `hover:text-black` inversions** (PracticeArena voice/send buttons, StrategyRoom Speak/mic) — button turns white with paper text on hover = invisible label mid-interaction. Map to `hover:bg-[#3a352c] hover:text-brand-bg-primary`.
- 🟡 **`prose-invert` in DraftingStudio facts/feedback/procedure panels** — dark-theme prose class renders light text on paper. Remove (or swap to `prose`).
- 🟡 **Invalid Tailwind sizes**: `p-4.5` (StrategyRoom:2158), `h-4.5 w-4.5` / `w-4.5 h-4.5` (PracticeArena ×4) — not in the default scale; classes silently no-op. Replace with `p-4` / `h-[18px]`.
- 🟡 **Raw green survives**: StrategyRoom:2259 `text-green-400 bg-green-500/10 border-green-500/20` "READY" badge + bare `border-amber-500` (:2229). Codemod covered emerald only. Violates design.md no-traffic-light rule.

### 3.2 screens/StrategyRoomScreen.tsx (2,287 lines)

- 🟡 **Rate-limit cliff in Synthesis Stage 5**: citation verification fires up to 12 *sequential* `/api/caselaw` calls (+1 Stage-2 retrieval) per run against a route limited to 15/min/IP. A second Synthesis within a minute eats 429s mid-pipeline and the whole run degrades to UNVERIFIED. Fix: cap candidates at 6, parallelize with concurrency ≤3, and reuse Stage-2 hits when the case already matched.
- 🟡 **Legacy dark palette baked into DeliberationBlueprint SVG**: hardcoded `#D6BA91` cream, `#0E1513`, `#2F3C38`, `#EAE6DF`, `#8EA38C`, `#455651` node fills/strokes + inline `<style>` block. Pre-dates Paper Dossier; nodes are near-black islands on a near-white panel. Re-map to ink/rule/clerk-red tokens.
- 🟡 **`(ctx as any).__verificationRows`** smuggles data through an any-cast instead of a typed `SynthesisContext` field. Add `verificationRows?: VerificationRow[]` to the interface.
- 🟡 **Copy law violations**: "Holographic Deliberation Blueprint", "Cognitive Engines Standby", "Submit a litigation premise or legal query in the consult workbench to activate the animated reasoning pipeline.", "Deliberation initiated. Mobilizing the Oracle reasoning engines...", "Oracle deliberated consensus". Rewrite per copy law.
- 🟢 Dead code: `setHoveredNode` state written never read (:349); empty `.float-1/.float-2/.float-3` CSS rules; unreachable `'Consult V4...'` placeholder ternary (:2128); empty `<span className="text-2xl "></span>` (:2268); `oracleStage` prop declared on DeliberationBlueprint but never destructured.
- 🟢 Desktop Copy button (:2055) lacks `.catch` on clipboard promise (mobile twin has one) → unhandled rejection when clipboard denied.
- 🟢 Mixed tabs/spaces indentation across the SYNTHESIS branch (~lines 1319–1490).
- ⚪ Third copy of HTTP-error humanization (`strategyApiError`) alongside `aiService.formatAiHttpError` and arena's `formatDreadlerApiError`. Consolidation candidate, low priority.
- ⚪ Oracle = 6 sequential LLM calls, Synthesis = 7 stages + extractor + verifications: minutes-long runs. Cancel exists and works; consider stage-level "skip" or running Stage-1 while retrieval happens (independent).

### 3.4 screens/DraftingStudioScreen.tsx (1,717 lines)

### 3.9 services/ + hooks/ + vision/

- 🟢 **storageService is the app's gold standard** — versioned envelopes, runtime shape guards, quota recovery that sheds non-critical keys, completed-session trimming. **Finding by contrast**: DraftingStudio and ResearchIDE bypass it with raw `localStorage` (see 3.4 / 3.5). Route both through `saveGenericState`/`readGenericState`.
- 🟢 **analyticsService is local-only** — events persist to localStorage under a soft cap, never leave the browser; tracks query *length*, never query text. Privacy posture is a feature; document it in the README.
- 🟢 **useTimer** is stale-closure-safe (callback refs, suppressed post-unmount setState, no re-render storms). Reference-quality hook.
- 🟢 exportService: proper Blob download with deferred revoke; filename sanitization present.
- 🟡 **usePrecedentSearch naming integrity**: pipelines named `legal-bert` and `haystack-hybrid` are, in reality, weighted keyword/synonym heuristics running client-side. No BERT, no haystack. A learner who knows what those words mean will feel misled — rename to honest labels (`keyword`, `weighted`, `hybrid`) or add a one-line "local heuristic search" disclosure.
- 🟢 vision/laptop: POS pipeline real; HSEmotion now correctly lazy (audit confirms dynamic import behind model probe). Mobile streamer requires explicit env config and degrades honestly.
- ⚪ voiceService (550 lines): thorough error taxonomy; browser-TTS fallback path is well designed. No defects found in review pass.

## 4. Cross-cutting

**Accessibility.** ~16 `<img>` without alt (many are decorative `alt=""`-candidates — audit each); no `aria-live` region on the arena chat feed or score changes (collapse banner is silent to screen readers); arena mobile drawers have `role="dialog"` but no focus trap/ESC; two `window.confirm`s (arena exit, snapshot restore) break the styled shell and are uninternationalized. Everything else (labels, `aria-pressed`, roles, focus rings) is above average.

**Performance.** Main bundle risks: constants chunk (see 3.10), `react-markdown` (118 KB) loaded by five screens — already code-split per route; ONNX wasm now lazy. Render hot-spots: arena re-renders full message list per stream delta (fine at current scale; virtualize only if sessions exceed ~200 messages). DraftingStudio writes localStorage per keystroke (see 3.4).

**Security.** App code: no injection surfaces found (all provider text sanitized before render; URLs scheme-checked; HMAC state tokens; origin allowlists; rate limits; no secrets client-side). Dependency advisories are the entire surface — see §5. The pasted-GitHub-token incident (2026-08-21) is resolved by rotation; nothing in the repo embeds secrets.

**Code health.** 15 `any`/`as any` (2 structural: `(ctx as any).__verificationRows`, DreadlerArena's `result: any` stream payload), 8 `ts-ignore/eslint-disable` (mostly justified with reasons), 0 console.log in shipped paths, 64 inline `style={{}}` (mostly canvas-adjacent, acceptable). Dead files: 3 (§3.8). Mixed tab/space indentation in StrategyRoom's Synthesis branch.

**Copy.** Copy law is applied to heroes/HUD/drawers app-wide, but StrategyRoom and DraftingStudio interiors still speak the old dialect (§3.2/§3.4 lists). One naming-integrity issue (§3.9 usePrecedentSearch).
