# LexForge workspace revamp

The app now uses one editorial workspace across its practice, writing, research,
and reasoning tools. The changes build on the clean-checkout and API-origin
repairs already in this branch.

## What changed

- New column mark, favicon, paper cover, practice brief illustration, product
  walkthrough, and jurisdiction entry.
- Persistent grouped navigation, route context, command search, a mobile drawer,
  guarded workspace exit, and one coach entry within the workspace.
- Overview with jurisdiction-specific local metrics, hearing history, real
  score charts, suggested cases, and direct workbench access.
- Hearing setup with grouped controls, a readable brief, bench preview, an
  accessible start action, and working case deep links.
- Shared daylight headings and controls across all modules. Removed decorative
  image strips and a duplicate application rail from research.
- Research manuscript/editing views with keyboard tabs, responsive split panes,
  closable panels, readable toolbars, and selection-driven research discovery.
- Readable category badges, profile cards, strategy modes, and 11px minimum
  labels. Deception Arena retains its dark identity.
- Command search refreshes active-hearing state, opens the actual coach, selects
  cases through setup links, and omits commands that previously led nowhere.

## Verification

The design review used production components and the repository's design
conventions; no design-system canvas service was connected. An isolated reviewer
inspected screenshots without source or diff context. A separate code review
checked state preservation, navigation, and responsive behavior.

Desktop rendering was inspected for landing, overview, setup, library, drafting,
research, strategy, personas, bench, performance, deception, and courtroom
practice. Phone layouts were inspected at 390 × 844. Contrast, overlapping
research controls, and the mobile start footer were corrected during review.

Browser interactions verified the case-card setup link, hearing launch, return
to overview, resume, manual manuscript section creation, keyboard view changes,
command navigation, both jurisdiction catalogues, drawer close/Escape controls,
focus restoration, and responsive split-pane behavior. AI-backed happy paths require a working Vercel API
deployment; the local Vite preview serves the UI only.

The complete Node 22 check covers the 12-function budget, generated gateway
parity, TypeScript, 18 TS test files, 5 Node regressions, 6 chain fixtures,
39 Python contract tests, and the production build.
